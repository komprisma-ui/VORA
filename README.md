# VORA — Digital Business Ecosystem

**Momentum Menuju Perkembangan**

VORA adalah platform digital business ecosystem yang menggabungkan commerce, member network, customer management, rewards, wallet, reporting, dan administration dalam satu sistem.

## Architecture
- React + Vite frontend
- Supabase PostgreSQL + Auth + RLS
- Server-side transaction/commission functions
- Capacitor Android shell
- Immutable financial ledger
- Audit trail

## Core principle
VORA rewards are generated from qualified commercial activity and real transactions. Recruitment alone does not create commission.

## Initial modules
Dashboard · Members · Network · Commerce · Wallet · Rewards · Products · Reports · Admin · Security

## Status
Foundation build in progress.
